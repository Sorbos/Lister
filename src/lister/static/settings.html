Scans folder

Lister picks up scans saved here. Set your scanner software to save into the same folder. Each scan is moved out of this folder once it's used, so use a folder just for card scans.

Waiting for back scans

After a scan arrives, Lister waits this long for its back scan before treating it as fronts only.

Stock description

Added to the end of every listing's description, after the card's own description (set per card in the Inventory) and the card details. Leave a blank line between paragraphs.

Defaults for listings

New inventory cards start with these settings (change them per card or in bulk in the Inventory). Stock shipping applies to every card without its own shipping cost, including cards already in the inventory. Leave it empty to use the cost in your eBay shipping policy.
